# 大学課題管理アプリ (TaskManagerApp)

大学生活の「課題」「時間割」「ToDo」「カレンダー」を一括管理できるAndroidアプリです。
Kotlin + Jetpack Composeで開発しています。

## 主な機能

### 課題管理
- 講義名・課題名・締切日を登録
- 提出済み/未提出の管理
- 講義名の入力候補表示

### 時間割
- マス目形式の時間割表示（学期切り替え対応）
- 講義の色分け、メモ機能
- 未提出課題のバッジ表示
- 長押しドラッグでの講義移動
- 休講・補講の登録とカレンダー連動

### ToDo
- カテゴリタブでの分類
- 完了済みの一括削除、並べ替え

### カレンダー
- 月表示（スワイプで月切り替え）
- 課題・講義・祝日・休講補講の統合表示
- 複数日にまたがる予定の登録

### 通知
- 今日の講義を知らせる通知（時刻カスタマイズ可）
- 締切前日に課題をリマインド

### その他
- ダッシュボード（起動時に今日の予定を表示）
- 長期休暇・試験期間の登録（該当期間は講義を非表示）
- データのバックアップ・書き出し（JSON形式）

## 使用技術

- 言語: Kotlin
- UI: Jetpack Compose
- データベース: Room
- 非同期処理: Kotlin Coroutines
- 設定の保存: DataStore
- バックグラウンド通知: WorkManager
- アーキテクチャ: MVVM (ViewModel + Repository)

## 開発の背景

もともとJavaFXで作成していたPC版の課題管理アプリを元に、機能を再設計しながらAndroidアプリとしてゼロから開発しました。
